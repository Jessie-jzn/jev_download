# ADR 0003：分类默认映射目录并允许自定义目标

## 状态

已接受

## 背景

本项目最终会服务多个收件箱。新收件箱通常希望“分类名就是目录名”，但用户也可能已经有固定的目录结构，例如把“发票”放在“财务/待报销”下。

## 决策

分类节点默认映射到同名目录路径。每个收件箱可以覆盖某个分类的目标目录，目标目录可以位于该收件箱的整理根目录下。界面同时展示分类路径和实际目标位置。

## 结果

- 新用户不需要额外配置就能得到可理解的目录结构。
- 有既有目录结构的用户可以复用原目录，而不必重命名业务分类。
- 自定义目标必须经过路径安全校验，不能指向整理根目录之外。
- 分类重命名不应默默改变已配置的自定义目标目录。
