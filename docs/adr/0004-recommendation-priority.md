# ADR 0004：分类建议的优先级

## 状态

已接受

## 背景

规则、历史选择、媒体元数据和 AI 都可能对同一个项目给出不同分类。如果没有固定优先级，用户无法预测系统会把项目移动到哪里，规则也可能被模型结果覆盖。

## 决策

分类和目标位置采用以下优先级：

1. 用户当前手动修改
2. 明确整理规则
3. 用户历史选择
4. 媒体元数据规则
5. AI 建议
6. 兜底分类或待确认

低优先级来源不得静默覆盖高优先级来源。发生冲突时，界面显示实际采用的来源。

## 结果

- 用户可以预测项目最终位置。
- AI 适合处理规则未覆盖的项目，而不是覆盖用户意图。
- 建议结果需要携带来源，便于解释和审核。
- 规则无效或目标不安全时，项目进入待确认状态。
