# ADR 0007：待处理项目跨重启保留并校验身份

## 状态

已接受

## 背景

收件箱可能持续产生文件，用户不一定会在同一次启动中审核完所有建议。只保存在浏览器内存中会丢失待处理项目；直接复用旧路径又可能移动已经被替换的文件。

## 决策

待处理项目持久化保存扫描快照、建议、来源和文件身份。应用重启后恢复列表。执行移动前重新检查文件身份和源位置；发现删除、移动或替换时使建议失效，并要求重新扫描或人工处理。

## 结果

- 用户可以稍后继续处理收件箱。
- 旧建议不会在源文件变化后静默生效。
- 待处理记录需要明确区分“待审核”和“源文件已变化”。
- 持久化数据必须只保存完成任务所需的信息，并遵守本机权限边界。
