# ADR 0005：从已确认的手动修正中学习

## 状态

已接受

## 背景

用户可能重复修正同一类项目。只依赖 AI 会重复消耗请求，也会让系统长期忽略用户偏好；但自动把一次修正变成规则会造成难以发现的错误移动。

## 决策

系统记录同一收件箱中已确认的手动分类和目标位置，识别出重复模式后生成规则建议。规则建议需要用户明确确认才能生效。学习结果按收件箱隔离，不跨目录共享。

新项目的移动建议进入待处理列表，不为每个新项目弹出即时对话框。用户可以逐项调整，也可以批量确认项目。

## 结果

- 常见修正可以逐渐转化为稳定规则。
- 用户始终知道规则何时产生，并可以拒绝或删除建议。
- 不同收件箱可以形成不同的个人习惯。
- 需要区分一次性人工选择、已确认规则和待确认学习建议。
