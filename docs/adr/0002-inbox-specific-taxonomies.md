# ADR 0002：分类体系属于收件箱

## 状态

已接受

## 背景

Downloads、照片目录和项目目录的整理目标不同。全局固定的“工作、学习、生活”等分类无法表达媒体目录或代码项目的实际组织方式，也会让 AI 在不适合的类别中被迫选择。

## 决策

每个收件箱拥有自己的分类体系。分类体系包含该收件箱可用的分类名称、目标位置模板和可选的规则。分类体系支持扁平分类和最多三级的层级分类。AI 只能在当前收件箱启用的分类中推荐，用户也只能从当前体系中选择。

## 结果

- 同一项目在不同收件箱中可以有不同的业务分类。
- 分类配置需要持久化，并在扫描快照中记录版本，避免配置变化后错误移动旧建议。
- 删除或重命名分类时，需要处理已有项目和历史记录的显示。
- 默认分类仍可作为新收件箱的初始模板，但不再是系统唯一分类集合。
- 分类节点的完整路径作为稳定分类身份，重命名和移动节点需要保留历史映射。
