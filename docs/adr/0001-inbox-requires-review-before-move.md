# ADR 0001：收件箱项目先建议再移动

## 状态

已接受

## 背景

本机智能资料管家需要处理 Downloads、桌面等持续接收新文件的目录。AI 分类和媒体元数据推断都可能出错，而移动文件会改变用户熟悉的路径。用户需要在看到分类和目标位置后决定是否执行整理。

## 决策

收件箱中新发现的项目先生成分类建议，进入待确认状态，并向用户展示建议分类和目标位置。用户确认后才提交移动操作。默认不允许监控任务直接移动项目。

用户可以对明确的整理规则单独开启自动移动，但这属于后续的显式配置，不改变收件箱的默认行为。

## 结果

- 新文件不会因为进入监控目录而意外改变位置。
- 用户可以在移动前修正分类、日期、地点和目标路径。
- 需要保存项目快照和建议状态，以便用户稍后处理。
- 监听和通知可以与文件移动解耦，后续可以先实现只读扫描。
- 自动整理必须绑定到用户明确配置的规则，并保留操作日志和撤销能力。
