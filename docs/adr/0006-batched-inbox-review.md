# ADR 0006：收件箱采用批量待处理审核

## 状态

已接受

## 背景

收件箱可能在短时间内接收多个下载文件。如果每个文件都立即弹窗，用户会被连续打断，也无法在同一批文件中比较分类结果。

## 决策

新项目进入待处理列表。系统生成分类建议和目标位置，但不直接移动，也不为每个项目弹出即时确认框。用户可以在列表中逐项修改或批量确认，确认后才提交移动批次。

待处理列表跨应用重启保留。项目保存扫描时的文件身份；如果源文件被删除、移动或替换，旧建议失效并需要重新扫描或确认。

## 结果

- 下载过程不会被多个确认窗口打断。
- 用户可以一次检查多个项目并统一执行移动。
- 待处理列表需要显示建议来源、置信度、目标位置和待确认原因。
- 长时间未处理的项目需要有明确状态，不应被当作已整理。
