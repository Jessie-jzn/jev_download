# 文件与文件夹分类整理工具

用户已确认：对父目录中的直属文件和直属文件夹统一分类，允许预览后直接移动，提供冲突检查、记录和撤销。

本地 Node.js 22 服务绑定 127.0.0.1，提供中文网页。用户选择父目录，扫描直属非隐藏、非符号链接的普通文件和目录；分类容器与依赖目录跳过。普通文件只使用名称、扩展名和大小，目录只读取两层、最多 40 条文件名样本，不读取文件内容。TypeSafe JavaScript SDK 的 choice 为每个项目推荐工作、学习、生活、影音、软件或其他标签，展示真实 confidence，不编造解释。

前端可调整类别、勾选项目、导出 JSON；默认先预览再移动到父目录/类别/原名。可显式开启高置信度自动整理，仅移动 confidence >= 0.85 且非其他的结果。未配置 Key 时可扫描和手动整理，AI 按钮明确不可用。

后端只接受本次扫描的随机项目 ID 与固定类别。检查父目录及源项目的类型和身份、符号链接、目标冲突；冲突跳过不覆盖。单进程串行执行移动；每次移动前持久化日志，成功后更新状态。撤销按日志反向操作，位置被占用或身份变化时保留数据并报告冲突。服务重启后可从日志恢复待定操作。保持源和目的在同一父目录，跨设备移动报错，不做删除式复制。旧目录操作记录没有类型字段时按文件夹处理，继续支持撤销。

接口仅供本机使用；校验 Host、Origin 和会话令牌。Key 仅从环境读取。测试在临时目录验证扫描、SDK 适配、移动、撤销、冲突和 HTTP 防护，不触碰真实用户文件。并发外部文件管理器修改同一目录不属于事务保证范围；执行时应避免外部修改。
