# 归屿 · 文件与媒体分类整理

本地整理工具：照片、视频和 Live Photo 按拍摄年月与国家城市整理；普通文件与文件夹通过 [TypeSafe JavaScript SDK](https://docs.typesafe.ai/sdk/javascript) 推荐分类，也可手动分类。移动与撤销保持文件字节和文件夹内部结构不变。

## 启动

要求 Node.js 22+。在项目目录运行：

```sh
npm install
cp .env.example .env
```

在 `.env` 中填写自己的 Key（不要提交或分享这个文件）：

```dotenv
TYPESAFE_API_KEY=你的TypeSafe_API_Key
PORT=3210
```

```sh
npm start
```

`npm start` 会用 Vite 构建 React 前端，然后由现有 Node 服务同时提供页面和本机 API。打开 **http://127.0.0.1:3210**。未配置 Key 也可以扫描、手动分类、移动和撤销。修改 `.env` 后需重启服务。

开发界面时先在一个终端运行 `npm run dev` 启动本机 API，再在另一个终端运行 `npm run dev:ui`，打开 Vite 提示的地址（默认 `http://127.0.0.1:5173`）。Vite 提供前端热更新，只代理 `/api`，不处理磁盘移动或 API 密钥；更改后端代码时请重启 Node 服务。发布前运行 `npm run build`，产物在被忽略的 `dist/`。

媒体元数据功能要求 macOS 和 Xcode 或 Command Line Tools 的 Swift 工具链。先检查并构建：

```sh
xcrun --find swiftc
npm run build:native
```

若找不到 Swift，可安装 Command Line Tools（`xcode-select --install`）。原生助手按源码哈希缓存在 `.data/bin/`。首次检测媒体功能或扫描时也会尝试构建。其他系统或构建不可用时会提示媒体功能不可用，普通文件与文件夹的手动整理和 Jev 分类仍可用；媒体候选解析失败时保留项目、显示失败状态并使用日期回退，不能保证 Live Photo 配对。

可选配置及精确默认值：

```dotenv
MEDIA_GEOCODE_CACHE_TTL_HOURS=24
MEDIA_HELPER_TIMEOUT_MS=120000
```

前者控制未解析地点结果多久后允许重试（小时），成功结果长期复用；后者是每次原生 helper 请求的超时（毫秒）。均接受正整数，空值或非法值回退上述默认值。超时最大为 `2147483647` 毫秒；缓存小时数转换为毫秒后须为安全整数。

## 使用

1. 点击「选择文件夹」打开 macOS 原生选择窗口，选好父目录后点击扫描。也可以手动输入绝对路径，例如 `/Users/你的用户名/Downloads`。其他系统可手动输入路径。
2. 普通项目可点击「AI 推荐分类」，或直接选择类别。媒体项目直接显示拍摄时间、来源和目标路径，不发送给 Jev。
3. 查看目的位置，调整普通标签或媒体的年、月、国家、城市、照片/视频类型，然后勾选项目。Live Photo 类型固定为照片；这些修改仅影响整理路径，不改写媒体元数据。默认只勾选置信度 ≥ 85% 且非「其他」的普通 AI 结果。
4. 点击「执行整理」，在确认框中确认移动。
5. 在「操作记录」查看结果，需要时点击「撤销此批次」。撤销遇到占用会跳过，可处理冲突后再次撤销。

移动示例：`下载/摄影教程` → `下载/学习/摄影教程`，`下载/课程表.pdf` → `下载/学习/课程表.pdf`。

可选的「自动整理」默认为关闭。显式开启后，下一次 AI 推荐结束会直接移动置信度 ≥ 85% 且非「其他」的结果，其余保留供人工处理。不要把置信度当成分类正确的保证。

## 媒体路径、日期与地点

媒体目标为 `<父目录>/<年>/<月>/<国家>/<城市>/<照片|视频>/<原文件名>`，例如：

```text
Downloads/2026/09/中国/上海/照片/IMG_2048.HEIC
Downloads/2026/09/中国/上海/照片/IMG_2048.MOV  ← 配套 Live Photo
Downloads/2026/09/中国/上海/视频/clip.MOV
```

日期依次取照片 EXIF/TIFF 或视频 QuickTime 元数据、严格有效的文件名日期（`YYYYMMDD_HHMMSS`、`YYYY-MM-DD HH-MM-SS`、`YYYY-MM-DD`）、文件系统创建时间；均不可用时使用 `未知日期/未知月份`。元数据含时区时保留其年月，没有时区则使用运行机器的当前时区并标记推断时间。文件名/创建时间是回退依据，建议在「时间待确认」中核对年月。

「允许 Apple 根据 GPS 查询国家和城市」默认关闭。勾选后需重新扫描才会查询，Apple 可能收到 GPS 坐标；照片、视频、音轨与缩略图留在本机。未开启、没有 GPS、离线或查询失败时，路径使用 `未知国家/未知城市`，可直接手动填写国家、城市。原始 GPS、配对标识和文件身份不出现在扫描响应中；界面仅显示是否有坐标。

地点缓存位于 `.data/geocode-cache.json`，权限 `0600`，只保存两位小数坐标键、国家、城市、状态与更新时间，不保存媒体路径或名称。原始坐标仅用于本机元数据处理及经同意的 Apple 查询；Jev 不接收媒体项目、媒体内容、缩略图或 GPS。普通项目名称仍可能包含私人信息，发送范围见下文。

Live Photo 仅在恰好一张照片和一个视频拥有相同非空元数据配对标识时组成一行；名称相同不足以配对。重复或缺失标识时分别显示，重复标识有提示。配对两文件一起移动到 `照片`，任一冲突则整组跳过；运行时部分失败会尝试安全回滚，无法确认状态时记录为需人工核对。

支持的照片扩展名：JPEG（`.jpg/.jpeg`）、HEIC/HEIF、PNG、TIFF（`.tif/.tiff`）、RAW（`.dng/.cr2/.nef/.arw/.raf`）。RAW 是否能解析取决于当前 macOS ImageIO 对相机格式的支持。视频支持 MOV、MP4、M4V。未列入的扩展名作为普通文件处理。元数据无法读取的候选项保留并提示失败，日期按上述规则回退。程序不解码媒体像素或音轨进行分析，也不转码文件。

扫描父目录时会跳过 Photos.app 的 `.photoslibrary` 图库包；直接选择图库本身、内部目录或指向内部的别名路径会明确拒绝（扩展名不区分大小写）。请先从 Photos 导出到普通文件夹再使用本工具。仅处理所选目录的直属媒体，不递归整理子文件夹中的照片。

## 范围与行为

- 默认分类：工作、学习、生活、影音、软件、其他。
- 整理父目录的直属文件和直属子文件夹。隐藏项目、符号链接、`node_modules` 和上述同名分类目录跳过。已有分类目录被视为整理容器，不会重复归类。
- 文件夹内部最多扫描两层、最多 40 条文件名样本；普通文件只读取名称、扩展名和大小，不读取内容。媒体读取本地元数据。每次最多 500 个逻辑项目，一组 Live Photo 计为一项。
- AI 请求为普通文件发送名称、类型、扩展名和大小；为普通文件夹发送名称与相对文件名样本。不会发送文件内容或父目录绝对路径，名称本身可能含有私人信息。
- 使用 `@typesafe-ai/sdk` 的 `TypeSafeClient.systemOne()` / `choice()`，使用 SDK 默认模型 `jev-latest`。最多并发 3 个请求，整个分类批次 120 秒后停止继续请求；未完成项目可重试或手动分类。
- 目标已存在时跳过，不合并。源目录已变化、路径含符号链接、目录不可读写时报告错误。不同设备之间不做复制删除式移动。
- 日志在 `.data/*.json`，先写日志后移动，重启仍可撤销。请保留 `.data`；不要同时运行多个实例。撤销保留空的分类容器。
- 文件和文件夹移动会改变绝对路径，已有快捷方式或项目引用可能需要更新。执行和撤销期间请勿用其他程序同时改动相同目录；外部并发操作不在本工具的事务保证范围内。
- 服务仅监听 `127.0.0.1`；校验 Host、Origin 和会话令牌。不适合部署公网或添加反向代理。

## 验证

```sh
npm run build:native
node --test test/media-integration.test.js
npm test
npm run check
npm run test:e2e
```

浏览器测试使用本机 Google Chrome，所有移动均在测试专用临时目录中执行。若没有 Chrome，可安装它或修改 `playwright.config.js` 的浏览器配置。

真实媒体集成测试以 Swift 在临时目录程序化生成 32×32 JPEG、HEIC、MOV、无日期/GPS 的 PNG，并生成包含期望元数据与 SHA-256 的 JSON manifest；验证真实原生 helper、Live Photo 配对、扫描、移动、重启后撤销及每个文件哈希。仓库不保存二进制夹具或个人媒体。MOV 使用 JPEG 编码的单帧视频，测试不依赖 H.264/HEVC 视频编码器。HEIC 合成短标识修正仅发生在夹具生成器中，严格校验 Apple MakerNote 布局后调整其 ASCII 长度，不影响生产解析规则。

macOS 沙箱若限制 IOSurface/CoreVideo 编码服务，HEIC 生成会失败；应在允许本机媒体编码服务的终端运行测试，测试不会跳过 HEIC/Live Photo 核心断言。非 macOS 仅跳过原生集成，通用测试仍运行。测试工具和生成文件位于临时目录；生产 helper 的编译缓存位于项目 `.data/`。

其他测试包括日期/地点回退、隐私与缓存、混合扫描、冲突与符号链接防护、Live Photo 回滚与持久日志恢复、SDK 请求序列化和 HTTP 校验。自动化测试未调用真实 Apple 反向地理编码；第一次人工地点验收需要显式同意及可用网络。SDK 使用本地模拟响应，媒体测试没有调用已配置的 TypeSafe Key；真实普通项目 AI 分类仍需有效 Key 与额度。

## 文件结构

- `src/organizer.js`：扫描、路径校验、移动、日志、撤销。
- `src/classifier.js`：TypeSafe 分类适配与结果校验。
- `src/media-native.js`、`native/MediaMetadata/`：原生元数据与 Apple 地点查询边界。
- `src/media-scanner.js`、`src/media-rules.js`、`src/geocode-cache.js`：媒体配对、日期/目录规则与地点缓存。
- `src/server.js`：本地 HTTP API 与 Vite 构建产物的静态服务。
- `ui/`：React 组件、浏览器状态与响应式样式；`index.html` 是 Vite 入口。
- `public/media-paths.js`：浏览器与服务端共用的媒体目标路径规则。
- `test/`、`e2e/`：核心、HTTP 和浏览器交互测试。
- `test/native/create-media-fixtures.swift`：临时合成媒体生成器。
